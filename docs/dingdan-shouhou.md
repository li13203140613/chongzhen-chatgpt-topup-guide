# 订单查询与售后

[← 返回首页](../README.md)

付款后可以在订单页查看订单状态、卡密和激活教程等信息。这一篇讲怎么查订单，以及几种常见状况各自怎么处理，内容整理自 chong-zhen 首页、支付宝充值页和服务说明。

## 怎么查订单

打开 [查询订单页](https://www.chong-zhen.com/orders)，输入下单时填的手机号或邮箱。能看到：

- 订单状态和处理进度
- 卡密和激活教程
- 开发票入口（下单时选了开票的订单）
- 收款凭证

建议付款后把订单号记下来。之后不管问什么，带着订单号沟通，不用从头解释一遍。

## 付款环节的几种情况

**扫完码，页面还显示待支付。**
支付宝确认后要过几秒页面才刷新。等一会儿没变化，去查询订单页看状态，不要急着再付一次。

**付款失败。**
先查订单状态，确认没有扣款，再重新下单。

**扣了款，但会员没到账。**
留好订单号，联系客服。Plus、Pro 10x、Pro 20x 正常是付款后 1-3 分钟到账；Pro 50x 是客服主动联系后一对一人工开通，进度同样在订单页能看到。

**银行卡被拒。**
被拒的订单不会扣款。银行有时会先显示一笔冻结款，交易没成功会自动撤销。处理办法见 [付款被拒的常见原因和处理](fukuan-beiju.md)。

## 激活环节

付款后页面给出卡密和操作说明，按订单页的教程粘贴 Session 完成激活，然后刷新 ChatGPT，设置里出现会员名称就是到账了。完整流程见 [充值方式和教程](https://www.chong-zhen.com/chongzhi-fangshi)。

激活不成功，先对照这三条：

1. 账号是不是还有正在生效的会员。会员不能叠加。
2. 注册邮箱是不是 Outlook、Hotmail。页面专门提醒不要用微软邮箱。
3. 登录的是不是你想充值的那个账号。

## 质保

每笔订单有 1 个月质保。非用户原因导致的会员中断，按服务条款处理。

下面这些用法页面明确列为可能影响质保：

- 用于反代、逆向、号池
- 提取 API Key
- 在 Codex 里问逆向相关问题或做敏感词测试
- 使用微软邮箱
- 多人共用一个账号

## 退款

页面的说法是：激活码生效前可以申请整单退款；会员已经生效的，改走 30 天质保。未开始处理的订单按规则申请，具体以 [服务条款](https://www.chong-zhen.com/terms) 为准。

## 额度问题不属于售后

额度是 OpenAI 按账号计算的，客服没法替你重置。用完了先在 ChatGPT 设置的用量页看是哪个窗口满了、几点重置，再决定等重置、换模型还是升档。
