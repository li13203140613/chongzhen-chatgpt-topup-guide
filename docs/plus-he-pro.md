# Plus 和 Pro 的区别

[← 返回首页](../README.md)

选哪一档，看的是你每周拿它干多少活。下面的说法整理自 chong-zhen 的 [套餐对比页](https://www.chong-zhen.com/plus/taocan-duibi) 和 [Pro 套餐页](https://www.chong-zhen.com/chatgpt-pro)，实际额度以你账号里 Usage 页面显示的为准，网站不固定承诺倍数或消息数。

## 先看结论

- 写文案、做周报、做表格和 PPT，偶尔读长文件：**Plus**。
- 每天用 Codex 写代码，Plus 的额度经常不够：**Pro 10x**。
- 高频开发、大型项目、长时间跑任务：**Pro 20x**。
- 只是日常聊聊的人，Plus 额度一般够用，不必急着上 Pro。

## 档位名称的变化

页面写明，10 月 30 日起 Pro 各档额度调整，名称也跟着变了：

| 现在的名称 | 以前的名称 | 变化 |
| --- | --- | --- |
| Pro 10x | Pro 5x | 额度是以前的 2 倍 |
| Pro 20x | Pro 20x | 原定的降额取消，仍是 20x 档 |
| Pro 50x | Pro 25x | 额度是以前的 2 倍，付款后人工开通 |

Plus 没有变化。已经开了旧档的人不用做任何操作，变化直接体现在账号里。

## 额度怎么理解

- 页面把额度叫「周额度」，就是一周能用的量，到期自动重置。
- 页面上「相当于多少 API 额度」的说法只是为了方便比较，不会给你一笔 API 余额。API 和 ChatGPT 账号是两套东西，API Key 另外计费。
- 额度只在 ChatGPT 和 Codex 里用。
- Plus 的用量按两个窗口算：5 小时窗口和每周窗口。Pro 各档目前没有 5 小时限制，只看每周额度，规则以账号用量页为准。

## 读长文件的差别

套餐对比页里有两行容易被忽略：单次能读多长。页面按文本估算给出的数字是：

| 档位 | 快速模型 | 推理模型 |
| --- | --- | --- |
| Plus | 约 40 页 | 约 320 页 |
| Pro | 约 250 页 | 约 680 页 |

实际会随内容变化。照这个口径，一两百页的材料，Plus 切到推理模型是读得下的。偶尔碰到长文件，切模型就行；每周都要处理几百页材料的，Pro 才省事。

## 办公场景

页面的对比表里，Excel、Word、PowerPoint 的扩展从 Plus 起才不算限量，Plus 也包含深度研究，具体额度以账号显示为准；想直接拿到能点开、能调整的表格和图表，也要 Plus 起。周报、复盘 PPT 这类活，Plus 正好够用。

## 写代码的场景

Codex 用的是 ChatGPT 会员额度，没有单独的充值入口。[Codex 充值页](https://www.chong-zhen.com/codex) 给的建议是：

- Plus：偶尔改代码、写脚本、读项目。
- Pro 10x：每天都用 Codex，Plus 经常不够。
- Pro 20x：长时间、多任务并行。

登录 Codex 时选「用 ChatGPT 账号登录」，不要用 API Key。

## 一个稳妥的做法

先开一个月 Plus，用满之后回头看两件事：

1. Office 扩展、深度研究一次都没碰过，下个月可以不开。
2. 隔三差五提示额度用完，就升 Pro 10x。

判断是不是「经常用完」，一个可选的粗算办法是每天看一眼 ChatGPT 设置里的用量页，记两三周：一周里好几次用完，再考虑升一档；偶尔用完，等重置就好。额度用完的四种处理办法见 [额度用完了怎么办](https://www.chong-zhen.com/jiaocheng/edu-yongwan)。

## 升级时注意

有效会员不能叠加。Plus 想升 Pro，要等 Plus 到期后再充；急用可以先联系客服。各档当前价格见 [会员价格页](https://www.chong-zhen.com/chatgpt-pro/jiage)。
