## 谁用得上

- **没有美金卡的用户**：页面价格按人民币折算显示，实际按美元结算，由支付宝按当日汇率扣款。
- **在 OpenAI 页面付款被拒的人**：卡没开境外支付、卡的国家和所在地区不一致，是最常见的两种原因。先看 [付款被拒怎么办](docs/fukuan-beiju.md)。
- **要报销的个人和团队**：下单时可以选企业发票，金额较大的可以对公打款。
- **用 Codex 写代码的人**：Codex 没有单独的充值入口，用的就是 ChatGPT 会员额度。

## 下单前先核对五件事

这五条来自 [Plus 充值页](https://www.chong-zhen.com/plus)，逐条过一遍能省掉大部分麻烦：

1. 账号现在是免费版，没有正在生效的会员。会员不能叠加，已有会员要等到期后再充。
2. 账号是你本人注册、自己在用的。
3. 注册邮箱不是 Outlook、Hotmail 这类微软邮箱。
4. 想好要不要发票。发票只能在下单时选，付款后不能补。
5. 备好一个手机号和支付宝。

## 从下单到激活

网站上的流程是这样走的：

1. **选套餐**。在 [首页](https://www.chong-zhen.com/) 选 Plus、Pro 10x 或 Pro 20x。
2. **填手机号**。这个号码用来核对订单、计算质保时间和找回订单，和你要充值的 ChatGPT 账号无关。
3. **选是否开发票**，并同意服务条款。
4. **支付宝付款**。电脑上扫码，手机上直接跳转。
5. **拿到卡密，按教程激活**。付款后页面会给出卡密和操作说明，按订单页的教程粘贴 Session 完成激活。
6. **刷新 ChatGPT**。设置里出现对应的会员名称，就是到账了。

## 价格是怎么算的

这里不写具体金额，因为会随汇率和调价变动，请看 [会员价格页](https://www.chong-zhen.com/chatgpt-pro/jiage)，最终以付款页显示的为准。计价规则是固定的：

- 订单按美元计价，页面上的人民币是按汇率折算的参考价，所以实际扣款和页面数字可能差一点点。
- 订单金额 = OpenAI 的价格 + 本站服务费。服务费有上限，写在 [服务条款](https://www.chong-zhen.com/terms) 的收费说明里，页面写明不另收其他费用。
- 各档都按月开通，没有季付、年付。
- 开票订单按开票价结算，比不开票略高，两种价格页面上分开列出。

## 发票和对公打款

- **发票要在下单时选**。勾选「需要企业发票」后，付款前会显示开票后的实际金额。
- **选了不开票就不能改**。页面原话的意思是：订单一律不支持改选、人工补开或补差价补开。
- **开票在订单页自助完成**。付款后到查询订单页找到订单，点开发票，填抬头、税号等信息，开好后发到邮箱。
- **对公打款**：金额较大的订单可以联系客服咨询对公打款，企业长期采购可以签合同。

详细步骤和几种报销凭证的区别，见 [企业采购与发票](docs/qiye-caigou-fapiao.md)，或网站的 [开发票教程](https://www.chong-zhen.com/jiaocheng/fapiao)。

## 常见问题

**1. 充进去的是谁的账号？**
你自己的。页面写的是「独享，充值到你的账号」，原来的聊天记录和自定义设置都保留。

**2. 下单要填什么？**
一个手机号，用于客服核对订单和质保时间，与充值账号无关。

**3. 多久到账？**
Plus、Pro 10x、Pro 20x 付款后 1-3 分钟内到账；Pro 50x 付款后客服主动联系，一对一人工开通。

**4. 已经有会员了，能再充一个月吗？**
不能叠加。要等现有会员到期、账号回到免费版之后再充。Plus 想升 Pro 也一样，急用可以先联系客服。

**5. 扫完码，页面还显示待支付怎么办？**
支付宝确认后要过几秒页面才刷新。等一会儿没变，就去查询订单页看状态。

**6. 付款金额和页面上的人民币不一样？**
订单按美元计价，页面人民币是折算的参考价，支付宝按付款当时的汇率扣款，会有小出入。

**7. 质保是什么？**
每笔订单有 1 个月质保，非用户原因导致的会员中断按服务条款处理。反代、多人共享等违规使用不在质保范围内。

**8. 能退款吗？**
页面写的是：激活码生效前可以申请整单退款；会员已经生效的，走 30 天质保。具体规则以服务条款为准。

**9. 哪些用法会影响质保？**
页面列了五条：不要用于反代、逆向、号池；不要提取 API Key；不要在 Codex 里问逆向相关问题或做敏感词测试；不要用微软邮箱；不要多人共用账号。

**10. 额度用完了怎么办？**
先在 ChatGPT 设置的用量页看是哪个窗口满了、几点重置。办法有四种：等重置、换一个模型、购买即时重置（部分账号可以）、升到更高档。额度是 OpenAI 按账号算的，客服没法替你重置。详见 [额度用完了怎么办](https://www.chong-zhen.com/jiaocheng/edu-yongwan)。

**11. Codex 怎么充值？**
Codex 用的是 ChatGPT 会员额度。会员开好后，在 Codex 里选「用 ChatGPT 账号登录」，登录刚开好会员的那个账号就行。不要用 API Key 登录，那是另一套按量计费。详见 [Codex 充值页](https://www.chong-zhen.com/codex)。

**12. 除了支付宝还能怎么付？**
网站也支持银行卡付款，要求卡能付美元并开了境外支付；付款弹窗里还可以切换成港币支付。被拒了就在弹窗里切回支付宝。
